# Game Edukasi Pengenalan Angka

## Deskripsi Proyek

**Game Edukasi Pengenalan Angka** merupakan sebuah proyek Tugas Akhir yang dikembangkan sebagai media pembelajaran interaktif untuk membantu pengguna mengenal angka dan memahami konsep dasar berhitung.

Aplikasi ini dikembangkan dalam bentuk permainan digital dengan memanfaatkan Godot Engine. Melalui pendekatan pembelajaran berbasis permainan (*game-based learning*), pengguna dapat belajar mengenali angka dan berlatih berhitung melalui interaksi yang tersedia di dalam game.

Proyek ini dibuat sebagai salah satu bentuk penerapan ilmu dan keterampilan dalam pengembangan aplikasi atau permainan digital.

## Tujuan Pengembangan

Tujuan dari pengembangan game edukasi ini adalah:

- Menyediakan media pembelajaran interaktif untuk pengenalan angka.
- Membantu pengguna memahami angka dan konsep dasar berhitung.
- Menghadirkan proses belajar yang lebih menarik melalui permainan digital.
- Mengimplementasikan teknologi pengembangan game dalam pembuatan media edukasi.

## Teknologi yang Digunakan

- **Game Engine:** Godot Engine 4
- **Programming Language:** GDScript
- **Project Type:** 2D Game
- **Version Control:** Git dan GitHub

## Fitur Utama

- Media pembelajaran pengenalan angka.
- Aktivitas permainan untuk melatih kemampuan berhitung.
- Interaksi pengguna melalui antarmuka permainan.

## Struktur Proyek

Berikut merupakan beberapa bagian utama dalam proyek:

- `project.godot` — File konfigurasi utama proyek Godot.
- `scenes/` — Berisi file scene yang digunakan dalam game.
- `scripts/` — Berisi kode program menggunakan GDScript.
- `assets/` — Berisi aset visual yang digunakan dalam game.
- `audio/` — Berisi aset suara.
- `fonts/` — Berisi jenis huruf yang digunakan dalam antarmuka game.

## Cara Menjalankan Proyek

1. Unduh dan instal [Godot Engine](https://godotengine.org/).
2. Clone repository ini atau unduh sebagai ZIP.
3. Buka Godot Engine.
4. Pilih **Import** dan arahkan ke file `project.godot`.
5. Buka proyek dan jalankan permainan melalui tombol **Run Project**.
